# Romanova Command Center

A Python-based productivity and focus tracker with AI integration. 

## Setup Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Create a file named `.env` in the main folder.
3. Add your DeepSeek API key to the `.env` file: `DEEPSEEK_API_KEY=sk-your_key_here`
4. Run the app: `python romanova_app.py`
